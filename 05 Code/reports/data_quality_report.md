## 3. How are geography differences handled?

- Every join is by numeric code: Census 2011 district code = Survey of India `DIST_LGD` (Palghar 681) = ICRISAT `INDC_DTC` = DataMeet `censuscode`. All 355 Census 2011 talukas match Survey of India `SUBDIS_LGD` codes exactly, so taluka boundaries are unchanged since 2011 apart from Palghar becoming a district.
- Sources without codes (Agriculture Census report, GR annexures) use explicit name-to-code tables (`src/s04_agcensus.py: REPORT_NAME_TO_CODE`, `data/manual/*.csv`). No fuzzy matching is used anywhere.
- Renamed districts: Aurangabad -> Chhatrapati Sambhajinagar (515), Osmanabad -> Dharashiv (525), Ahmednagar -> Ahilyanagar (522). Codes are unchanged; all names are kept in `district_crosswalk.csv`.
- Rainfall is aggregated separately over A and B polygons (active boundary source: Survey of India; A = Thane and Palghar polygons dissolved).

## 7. What anomalies were found?

1. **Village Directory irrigation labels are swapped.** Source-wise irrigated areas sum to the column labelled 'Total Unirrigated Land Area' in 43,661 of 43,665 villages (to the column labelled 'Area Irrigated by Source' in only 1,086). The code maps raw -> analytical fields explicitly; the raw file is untouched.
2. **Negative values** in the true-unirrigated column: 345 villages. Active policy `keep_raw`; the clipped alternative changes a district's irrigated share by at most 1.95 percentage points.
   Irrigated + unirrigated equals net area sown in every village except 2 (Jalgaon, Nanded); e.g. one Jalgaon village has net area sown 0 but 3,401 ha unirrigated, so Jalgaon's irrigated + rainfed shares sum to 100.4%. Kept as published.
3. **Agriculture Census Table 5 errors:** Dhule, Chandrapur. Chandrapur's 2010-11 row reproduces Gondia's distribution; Dhule's Small/Large columns disagree with Tables 2 and 26. Features use Table 2, which equals the Table 26 tahsil totals in all 33 districts (max |difference| = 0 holdings).
4. **Survey of India sub-district layer:** Dhule's 4 sub-districts carry `DIST_LGD` 598 instead of 498 (district layer is correct). Sub-district DISTRICT names are in a legacy font encoding; codes are used instead.
5. **ENSO classification check:** pipeline reproduces 919/919 ONI v6 and 915/919 RONI cells of NOAA's published episode tables. Mismatches: RONI 1984 FMA (-0.45); RONI 1984 MAM (-0.59); RONI 1984 AMJ (-0.62); RONI 1984 MJJ (-0.51) - a 1984 La Nina run whose first value is exactly -0.45 in the 2-decimal file (NOAA likely rounds from more precision); no El Nino season is affected.
6. **Rainfall grid:** districts intersecting < 10 grid cells: Mumbai Suburban (4), Mumbai (2); every grid cell intersecting every district had valid data on every day, so the valid-cell renormalisation was never triggered. Valid cells in the Maharashtra box: 1181 in every year (grid mask unchanged 1950-2024).
7. **Village Directory vs ICRISAT net area:** VD net area sown / ICRISAT net cropped area (2010-12) median 1.11, range 0.91-1.74 (max: Thane). Different reference years/definitions; VD is used because it is the Census 2011 source.
8. **2023 revenue-circle GR (1021 circles):** spelling: 'Akola' printed for Akole taluka of Ahmednagar (also listed as अकोले); probable GR error: Gevrai is a Beed taluka but is listed under Osmanabad/Dharashiv; overlap: Madha was already a declared (moderate) taluka in the main 2023 GR. Taluka spelling variants also occur, so only circle COUNTS are used; a taluka-level share is not constructed.
9. **Prototype definitions:** the prototype's `Marginal_Worker_Share_pct` divided by total population; both denominators are now produced. The prototype rainfall CSV is not used (provenance unverified).
10. **IMD 2025:** the IMD download page still states 1901-2024; the 2025 file is complete (365 days) but its final/provisional status is not documented. It is therefore excluded from the primary study period (1950-2024) and kept in data/raw for a sensitivity check only.
11. **Implausibly high district-years in the official IMD grid** (monsoon > 2.0x baseline; flagged, NOT altered; NOT VERIFIED as errors - no published correction found): Jalgaon 1962 (2.9x); Buldana 1962 (2.2x); Nanded 1988 (2.2x); Jalna 1962 (3.9x); Aurangabad 1962 (2.6x); Pune 2005 (4.9x); Pune 2009 (2.0x); Ahmadnagar 2005 (2.1x); Solapur 1962 (2.5x); Satara 2005 (2.9x). None of these years is an El Nino monsoon year under either index, so they enter the El Nino-year features only through the baseline. Largest baseline change if they were excluded: 10.2% (Pune). Config `rainfall_extreme_values`: primary = keep all published values; the excluded-baseline version is sensitivity only.
